# FitTrack — Morning checklist 📱

Tap through this on your phone (or computer). Total time: ~3 minutes.

## Setup (once)
- [ ] Open the app (see README for how to get it on your iPhone home screen).
- [ ] It opens to **Today** with a welcome card and no data. ✅ = starts empty.

## 1. Targets
- [ ] Go to **Settings** → targets show 2800 / 180 / 260 / 100 / 30 / 9000.
- [ ] Change Protein to another number, tap **Save targets**.
- [ ] Go to **Nutrition** → the Protein row shows your new target.

## 2. Nutrition
- [ ] Tap **+ Log entry**, enter today's fasted weight + a couple of macros, **Save**.
- [ ] The "Today vs targets" bars update.
- [ ] Force-close the app and reopen → the entry is still there. ✅ = data persists.
- [ ] Tap **Edit** on the entry, change a number, **Save** → it updates.

## 3. Workouts
- [ ] Go to **Workouts** → Day 1–4 are there with the right exercises.
- [ ] Tap **Start session** on Day 1, enter a weight + RIR for a set, **Save session**.
- [ ] Tap **Start session** on Day 1 again → "Last (today): …kg @… RIR" shows above the inputs. ✅ = progressive overload data. Tap **Cancel** → **Discard**.
- [ ] Tap **Edit program**, rename a Day 4 placeholder exercise, **Save program** → it sticks.

## 4. Progress
- [ ] Go to **Progress** → the weight chart shows your point(s) from step 2.
- [ ] Optional: add a progress photo and a note.

## 5. Backup (do not skip)
- [ ] **Settings → Export backup** → a `.json` file downloads/saves to Files.
- [ ] (Trust test, optional: **Import backup** with that file → everything comes back.)

## 6. Offline
- [ ] Turn on Airplane Mode, close and reopen the app → it loads and shows your data.

If every box ticks: you're set. Log tomorrow morning's weight and go train. 💪
